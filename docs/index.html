File Manager

Active

OaSis OS File Manager is a modern, dual-panel file browser built for speed and simplicity. Navigate your filesystem, preview files instantly, and run commands from the built-in terminal panel — all in one unified interface.

✓
Info: File Manager is bundled by default in OaSis OS v2.0+. On older releases, install it manually via the App Store or run sudo oasis-pkg install file-manager.

Installation

Use the OaSis package manager to install File Manager. Open a terminal and run the following commands:

bash 
# Update package list first
sudo oasis-pkg update

# Install File Manager
sudo oasis-pkg install file-manager

# Confirm version
oasis-fm --version
# → OaSis File Manager v2.4.1

Configuration

After installation, edit the config file at ~/.config/oasis/file-manager.yaml to customize the application to your workflow:

yaml 
# ~/.config/oasis/file-manager.yaml

theme:         dark            # dark | light | system
split_view:    true
show_hidden:   false
default_path:  ~/Documents
sort_by:       name            # name | size | date | type

terminal_panel:
  enabled:     true
  height:      200
  shell:       /bin/oash

cloud_sync:
  provider:    oasis-cloud
  auto_sync:   true
  interval:    300             # seconds

First Launch

Follow these steps to get started after a fresh installation.

  1. 1

    Open File Manager

    Click the File Manager icon in the OaSis dock, or press Super and search for "File Manager". You can also launch it from the terminal with oasis-fm.

  2. 2

    Connect Cloud Storage

    Navigate to Settings → Cloud Sync and sign in with your OaSis Cloud account to enable automatic file synchronization across your devices.

  3. 3

    Enable Split View

    Press Ctrl + Shift + S, or go to View → Split View to activate dual-panel mode for efficient file transfers and comparison.

  4. 4

    Set Up Preferences

    Open Edit → Preferences to configure your default directory, file sorting, display density, and custom keyboard shortcuts.

Scripting & Automation

File Manager exposes a native scripting API via the OaSis Script Engine. Automate file operations in your .osc scripts:

javascript 
// OaSis Script Engine — automate.osc
import { FileManager } from '@oasis/file-manager';

const fm = new FileManager();

// Navigate to a directory
fm.navigate('/home/user/Projects');

// List files with metadata
const files = await fm.listFiles({ hidden: false });
files.forEach(f => console.log(f.name, f.size));

// Copy file to backup folder
await fm.copy('./report.pdf', './backups/report.pdf');

// Trigger cloud sync
await fm.cloudSync.push();
