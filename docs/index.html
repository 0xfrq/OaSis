OaSis OS

32-bit x86 educational operating system built from scratch.

Overview

OaSis is a minimal operating system for x86 (i386) that boots via GRUB, runs in 32-bit protected mode, and includes a shell, filesystem, C compiler, built-in assembler, and user mode (ring 3) support.

Build & Run

Prerequisites:

sudo apt install gcc nasm grub2-common xorriso qemu-system-x86

Build and run:

make          # build kernel.bin + oasis.iso
make clean    # clean artifacts
make run      # boot in QEMU

Boot & Kernel

OaSis boots via GRUB (Multiboot-compliant). The boot sequence:

  1. GRUB loads kernel.bin at 1MB physical
  2. Entry point sets up stack, calls kernel_main
  3. GDT, IDT, PIC, timer, keyboard initialized
  4. E820 memory detection, PMM, paging enabled
  5. OAFS filesystem loaded, syscalls initialized
  6. Shell prompt appears

Memory Management

Physical Memory Manager (PMM) uses a bitmap allocator. Paging uses 4KB pages with identity mapping for the first 4MB and higher-half kernel mapping at 0xC0000000+. Kernel heap allocator (kmalloc/kfree) uses a free-list with splitting and coalescing.

Paging & Process Isolation

Each user task gets a cloned page directory from the kernel. Kernel pages (identity map, higher-half) are mapped without PTE_USER. User pages (code, stack, heap) are mapped with PTE_USER. The task scheduler switches CR3 when switching between tasks with different page directories.

System Calls

23 system calls via int 0x80. Arguments in registers: eax = syscall number, ebx- edx = args. Return value in eax.

The handler detects whether the call came from ring 0 or ring 3 by checking CS at [esp+36], and handles the different iret frame layouts accordingly.

User Mode (Ring 3)

User code runs via the user /file.asm command. Flow: assemble -> create user task with cloned page dir -> switch_to_user() via iret to ring 3. On SYSCALL_USER_EXIT (21), the handler redirects iret to user_return_to_shell which restores CR3 and returns to the shell.

Task Scheduler

Preemptive round-robin scheduler driven by timer IRQ (100Hz). Tasks are linked in a circular list. task_switch() selects the next task and updates CR3 for per-task page directories.

OAFS Filesystem

Oasis File System — custom inode-based filesystem on the block device. 1024 inodes, 8192 blocks (512 bytes/block). 12 direct blocks + 1 indirect block (128 pointers) per file = ~70KB max file size. Directories support up to 168 entries (12 blocks x 14 entries).

occ Compiler

occ (OaSis C Compiler) compiles a subset of C to x86 assembly, which is then assembled by the built-in assembler.

Supported:

  • Types: int, char
  • Control: if/else, while, for
  • Functions with parameters (int add(int a, int b))
  • Array subscript (arr[i])
  • String literals, arithmetic, comparisons
  • External symbols: printf, malloc, free, sys_open, sys_read, sys_write_fd
int main() {
    printf("hello world");
}
// > occ hello.c

Built-in Assembler

Full x86 32-bit assembler supporting mov, add, sub, cmp, xor, and/or, jmp/je/jne/call/ret, push/pop/pusha/popa, times directive, db (data bytes), segment registers, labels, and external symbols.

Text Editor

Nano-like editor with arrow key navigation, Ctrl+S (save), Ctrl+X (exit), status bar, scrolling, and tab support (inserts 4 spaces).

Logging

Circular buffer (4096 bytes). Auto-logs exceptions with register dump. View with dmesg. Safe for interrupt context.
